Conversation interface

Optional: connect an AI service
For safety, this app does not include an API key. Putting a private API key directly into a phone app can expose it. Only use an endpoint you trust. The endpoint must accept an OpenAI-compatible chat-completions request and allow browser access (CORS).

Connection settings are saved in local browser storage. Avoid using this on a shared device. Live mode may incur charges from your provider.
